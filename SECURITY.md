# Segurança

Não publique tokens, cookies, snapshots de conta, logs de autenticação ou capturas com dados pessoais em issues.

Para comunicar uma vulnerabilidade, use a aba Security do GitHub se o relato privado estiver disponível. Se não estiver, abra uma issue apenas solicitando um canal privado, sem detalhes exploráveis ou dados sensíveis.

Esta é uma versão experimental, com uma API privada do WidgetKit e integração não pública do site Claude. Não há auditoria de segurança independente nem promessa de suporte a futuras versões do macOS.
